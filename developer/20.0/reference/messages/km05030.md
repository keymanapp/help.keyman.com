---
title: KM05030: WARN_CopyWithoutIdIsDeprecated
---

|            |           |
|------------|---------- |
| Message    | Deprecated usage: you should pass the target id as the second parameter on the command line rather than the final component of the output path\. |
| Module     | [kmc.InfrastructureMessages](kmc.infrastructuremessages) |
| Identifier | `WARN_CopyWithoutIdIsDeprecated` |


This change was made so that the `--out-path` parameter for `kmc copy`
will have the same meaning as other kmc commands.
