---
title: KM00035: HINT_MultipleTouchFormsWithoutMinDeviceWidth
---

|            |           |
|------------|---------- |
| Message    | When multiple touch forms are present, 'minDeviceWidth' is required to differentiate them |
| Module     | [kmc-ldml.LdmlCompilerMessages](kmc-ldml.ldmlcompilermessages) |
| Identifier | `HINT_MultipleTouchFormsWithoutMinDeviceWidth` |


Touch forms are differentiated by their minimum device width, so when there is
more than one, at most one form may omit the `minDeviceWidth` attribute.
