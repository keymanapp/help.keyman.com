---
title: KM00032: HINT_TouchLayerHasModifiers
---

|            |           |
|------------|---------- |
| Message    | Touch layer with id "&lt;param&gt;" for touch form with minDeviceWidth=&lt;param&gt; should not have a "modifiers" attribute |
| Module     | [kmc-ldml.LdmlCompilerMessages](kmc-ldml.ldmlcompilermessages) |
| Identifier | `HINT_TouchLayerHasModifiers` |


Touch layers must have an `id` attribute, but should not have a `modifiers`
attribute, and conversely, hardware layers must have a `modifiers` attribute
and should not have an `id` attribute.
